## 📁 /scripts Directory - Data Pipeline

### Module 1: Data Enrichment
**File:** `fetch_data.py` (180 lines)

**What it does:**
- Reads hospital_base_dataset.csv
- Fetches real AQI data from OpenAQ API
- Fetches weather data from OpenWeather API
- Creates enriched dataset

**How to run:**
```bash
cd scripts
python fetch_data.py
```

**Input:** data/hospital_base_dataset.csv
**Output:** data/final_dataset.csv

**Key Functions:**
- fetch_aqi_data() - Get AQI from OpenAQ
- fetch_weather_data() - Get weather from OpenWeather
- enrich_dataset() - Main pipeline

---

### Module 2: Data Preprocessing
**File:** `preprocess.py` (300 lines)

**What it does:**
- Handles missing values
- Encodes categorical columns
- Validates data quality
- Prepares features and target

**How to run:**
```bash
python preprocess.py
```

**Input:** data/final_dataset.csv
**Output:** Preprocessed data, saved encoders

**Key Classes:**
- DataPreprocessor:
  - load_data()
  - handle_missing_values()
  - encode_categorical_columns()
  - create_features_and_target()
  - validate_data()

---

### Module 3: Model Training
**File:** `train_model.py` (350 lines)

**What it does:**
- Trains RandomForestRegressor
- Evaluates model (MAE, RMSE, R²)
- Displays feature importance
- Saves trained model

**How to run:**
```bash
python train_model.py
```

**Input:** data/final_dataset.csv
**Output:** models/patient_inflow_model.pkl, models/encoders.pkl

**Key Classes:**
- ModelTrainer:
  - load_and_preprocess_data()
  - split_data()
  - build_model()
  - train_model()
  - evaluate_model()
  - get_feature_importance()
  - save_model()

## 📁 /app Directory - REST API

### API Server
**File:** `app.py` (450 lines)

**What it does:**
- Runs Flask REST API
- Provides 3 endpoints: /health, /predict, /recommend
- Handles input validation
- Loads model for inference

**How to run:**
```bash
cd app
python app.py
```

**Runs on:** http://0.0.0.0:5000

**Endpoints:**
- GET /health - Health check
- POST /predict - Patient count prediction
- POST /recommend - Medicine recommendations

**Key Functions:**
- load_model_and_encoders() - Load pickled model
- validate_prediction_input() - Input validation
- prepare_features() - Feature encoding
- predict() - Prediction endpoint
- recommend_medicines() - Recommendation endpoint

## 🚀 Typical Workflow

### First Time Setup

1. **Read Documentation**
   ```bash
   cat README.md
   cat QUICK_START.md
   ```

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Setup API Key**
   ```bash
   copy .env.example .env
   # Edit .env with your OpenWeather API key
   ```

4. **Run Automated Setup**
   ```bash
   python setup.py
   ```

1. **Data Enrichment**
   ```bash
   cd scripts
   python fetch_data.py
   ```

   ```bash
   python preprocess.py
   ```

3. **Model Training**
   ```bash
   python train_model.py
   ```

4. **Start API**
   ```bash
   cd ../app
   python app.py
   ```

5. **Test API** (in another terminal)
   ```bash
   cd ..
   python test_api.py
   ```

## 🔧 Customization Guide

### Need to Customize?

1. **Change Hospital Location**
   - Edit `config.py` line 12-13
   - Set HOSPITAL_LAT and HOSPITAL_LON

2. **Add More Diseases**
   - Edit `config.py` DISEASE_TYPES list
   - Add to MEDICINE_DATABASE dict

3. **Modify Model Hyperparameters**
   - Edit `config.py` MODEL CONFIGURATION section
   - Re-run train_model.py

4. **Change API Port**
   - Edit `app/app.py` last line
   - Change port parameter

5. **Add More Medicines**
   - Edit `config.py` MEDICINE_DATABASE
   - Add disease-medicine mappings

## 🐛 Troubleshooting

### Problem: "Module not found"
```bash
# Solution: Reinstall dependencies
pip install -r requirements.txt --force-reinstall
```

### Problem: "Model file not found"
```bash
# Solution: Train model first
cd scripts
python train_model.py
```

### Problem: "API key error"
```bash
# Solution: Edit .env file
cat .env
# Make sure OPENWEATHER_API_KEY is set
```

### Problem: "Port already in use"
```bash
# Solution: Change port in app/app.py
# Or kill process using port:
# Windows: netstat -ano | findstr :5000
# Linux: lsof -i :5000
```
