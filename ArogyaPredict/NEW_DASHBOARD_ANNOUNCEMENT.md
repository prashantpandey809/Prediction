## 🎯 Workflow Example

### Scenario: Daily Hospital Check

1. **Open Dashboard**
   - Go to http://localhost:5000
   - See today's patient forecast

2. **Check Status**
   - View critical medicine alerts
   - Check expiring medicines

3. **Make Prediction**
   - Input today's temperature, humidity, AQI
   - Predict patient count

4. **Get Recommendations**
   - Enter predicted number
   - Select disease type
   - Get smart stock recommendations

5. **Order Medicine**
   - Review recommendations
   - Check criticality levels
   - Order as needed
