## 🆘 Troubleshooting

### Issue: Dashboard Won't Load

**Solution:**

```bash
1. Check server running: python -m app.app
2. Check port 5000 is free
3. Clear browser cache (Ctrl+Shift+Delete)
4. Try incognito mode
5. Check http://localhost:5000/health
```

### Issue: Medicines Not Showing

**Solution:**

```bash
1. Restart Flask server
2. Refresh browser (Ctrl+F5)
3. Check config.py updated
4. Check browser console (F12)
```

### Issue: Predictions Give Error

**Solution:**

```bash
1. Train model: python scripts/train_model.py
2. Restart Flask server
3. Check input values are valid
4. Read error message carefully
```
